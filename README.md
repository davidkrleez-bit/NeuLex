# NeuLang

Product plan for NeuLang, a Flutter app that teaches high-frequency English words and phrases through stories, with spaced review. Nothing is built yet. This repository is the plan.

## Read this first

1. [How it all works](docs/plan/00-how-it-all-works.md) — plain-language walkthrough of the whole system.
2. [Plan index](docs/neulang-plan.md) — every section, the recommendations, and the decisions still open.

Binding decisions are in [project context](docs/project-context.md). The planning brief is in [internal/source/neulex-planning-brief.md](internal/source/neulex-planning-brief.md).

## On your computer

Clone this repository, then in Cursor choose **File → Open Folder** and open that folder. Edits there are on your machine.

There is no app to run and no install step.
